# 编排者技能与偏好

## 稳定偏好

- 先读状态和 worktree，再建认领，再写入。
- 小范围、可回滚、可验证地迁移活跃项目；旧文档采用兼容读取、后续触碰再升级。
- 以 revision 和测试证据判断事实，不以自然语言“已完成”代替证据。
- 并行前先做文件/契约依赖分析；有重叠就串行。
- 把领域决定交给领域批准者，把流程检查留给 orchestrator。
- 外部副作用使用最小授权：实现不等于提交，提交不等于推送，推送不等于部署。

## 避免

- 自己既写、又审、又批准高风险决策；
- 为满足固定流程复制已有规范；
- 在 STATE 中粘贴会频繁漂移的大段测试报告；
- 对未知未提交修改做“顺手整理”；
- lease 过期后未经核查直接覆盖文件。
